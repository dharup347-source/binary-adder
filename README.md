# Binary Adder

A simple Python program that adds two binary numbers.

This project helps **Electronics & VLSI** students understand how binary addition works.

## Features

- Takes two binary numbers as input
- Adds them and shows the result in binary
- Also shows the decimal equivalent
- Handles invalid binary inputs

## How to Run

```bash
python binary_adder.py
```

## Example

```
Enter first binary number: 1011
Enter second binary number: 1101

Binary Result : 11000
Decimal Result: 24
```

## What You Will Learn

- Converting binary to decimal and back
- Using `int(value, 2)` and `bin()`
- Input validation for binary numbers
- Building a clean interactive program
